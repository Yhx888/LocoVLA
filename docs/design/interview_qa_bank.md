# 47 面试题库与自测题

> 关卡：47（oral_defense 外部人工答辩准备；本题库不能替代真人评审）
> 文档目的：覆盖课程所有章节的面试题，每题含参考答案，可作为答辩自测和复习资料。

## 第 00-05 关：基础与建模

### Q1.1（00 关）为什么选择 MuJoCo 而不是 PyBullet 或 Isaac Gym？
参考答案：MuJoCo 在接触精度、计算效率、可微分仿真方面平衡较好；课程目标是控制与感知，不是大规模 RL 训练，MuJoCo 的 Python 绑定和 MJCF 配置对入门更友好。

### Q1.2（01 关）nq=13、nv=12、nu=6 分别代表什么？为什么不相等？
参考答案：nq 是广义坐标维度（含 7 维自由基座：3 平移 + 4 四元数），nv 是广义速度维度（含 6 维自由基座：3 线速度 + 3 角速度），nu 是执行器数（4 腿部位置 + 2 轮端力矩）。四元数 4 维对应角速度 3 维，所以 nq-nv=1。

### Q1.3（02 关）为什么用四元数而不是欧拉角表示姿态？
参考答案：四元数无奇异性、无万向锁、归一化后单位长度便于插值；欧拉角在 ±90° 俯仰时退化。课程用 quaternion_to_pitch 从四元数提取俯仰角，仅在状态反馈时转换。

### Q1.4（03 关）坐标变换 P_world = R * P_body + t 的物理含义？
参考答案：把机身坐标系下的点变换到世界坐标系。R 是旋转矩阵（描述机身相对世界的朝向），t 是平移向量（机身原点在世界坐标系的位置）。

### Q1.5（04 关）小角度线性化 sin(θ)≈θ 的有效范围？
参考答案：误差 < 1% 时 θ < 0.1 rad（约 5.7°）；误差 < 5% 时 θ < 0.25 rad（约 14°）。Upkie 平衡时 θ 通常 < 0.05 rad，线性化充分。

### Q1.6（05 关）低通滤波器的截止频率如何选择？
参考答案：截止频率应高于控制带宽（100Hz 控制对应 10Hz 带宽），低于噪声主要频率（IMU 噪声通常在 50Hz 以上）。课程取 fc=20Hz，平衡降噪和滞后。

### Q1.7（01 关）MJCF 中 `<freejoint>` 与普通 `<joint>` 的区别？为什么 Upkie 根部用 freejoint？
参考答案：freejoint 释放 6 个自由度（3 平移 + 3 旋转），普通 joint 只释放 1-3 个旋转或滑动自由度。Upkie 是浮动基座机器人，需要在世界中自由跌倒、移动、转向，因此根部必须用 freejoint；普通 joint 会把机器人钉死在某一自由度上，无法模拟真实跌倒。

### Q1.8（02 关）MuJoCo 的 `mj_step` 与 `mj_forward` 有什么区别？分别用在什么场景？
参考答案：`mj_step` 推进物理一步（计算前向动力学 + 积分位置/速度），用于仿真主循环；`mj_forward` 只计算前向运动学/动力学（位置、雅可比、接触）但不积分，用于"给定状态查询观测量"的场景，如可视化、传感器读数、控制器在线评估。

### Q1.9（05 关）一阶低通滤波器 `y[k] = α*x[k] + (1-α)*y[k-1]` 中 α 与截止频率 fc 的关系？
参考答案：α = 2π*fc*Ts / (1 + 2π*fc*Ts)，其中 Ts 是采样周期。fc 越高 α 越接近 1（几乎不滤波），fc 越低 α 越接近 0（强滤波但滞后大）。课程 Ts=0.01s、fc=20Hz 时 α≈0.557。

## 第 11-18 关：经典控制

### Q2.1（11 关）Upkie 模型契约中"自由基座"是什么意思？
参考答案：根部没有固定到世界，允许 6 自由度运动（3 平移 + 3 旋转）。这意味着机器人可以跌倒、移动，不限于固定基座控制。

### Q2.2（12 关）PD 控制律 u = Kp*e + Kd*ė 中 Kp、Kd 如何调参？
参考答案：Kp 决定刚度（响应速度），Kd 决定阻尼（抑制振荡）。课程取 Kp=3.0, Kd=0.8，通过临界阻尼条件 2*sqrt(Kp*J) ≈ Kd 推导。过大会振荡，过小响应慢。

### Q2.3（13 关）积分饱和（windup）是什么？如何避免？
参考答案：误差持续同向时积分项累积过大，导致反向超调。抗饱和方法：积分限幅、条件积分（误差大时停止积分）、反算反卷绕（back-calculation）。

### Q2.4（14 关）轮式倒立摆的线性化模型状态变量是什么？
参考答案：四状态 [x, ẋ, θ, θ̇]：位置、速度、俯仰角、俯仰角速度。控制输入是轮端力矩 τ。

### Q2.5（15 关）极点配置与阻尼比的关系？
参考答案：二阶系统极点 s = -ζωn ± jωn*sqrt(1-ζ²)。ζ=0 无阻尼振荡，ζ=1 临界阻尼，ζ>1 过阻尼。课程要求 ζ≥0.7 保证收敛速度和振荡权衡。

### Q2.6（16 关）可控性矩阵秩为什么能判断系统能否控制？
参考答案：可控性矩阵 [B, AB, A²B, ...] 的秩等于状态维度时，系统完全可控。物理含义：通过有限步控制输入可以驱动状态到任意目标。

### Q2.7（17 关）LQR 的代价函数 J = ∫(xᵀQx + uᵀRu)dt 中 Q、R 如何选择？
参考答案：Q 是状态偏差权重（对角元素越大对应状态越重要），R 是控制能耗权重（越大越省力）。课程取 Q=diag(1,1,1,1), R=1，平衡状态收敛与控制能耗。

### Q2.8（18 关）偏航和高度控制器为什么要镜像腿目标？
参考答案：左右腿对称才能保持机身水平。镜像保证 left_hip = -right_hip, left_knee = -right_knee，避免单边偏置导致侧倾。

## 第 19-23 关：状态估计与优化

### Q3.1（20 关）Kalman 滤波的预测和更新两步分别做什么？
参考答案：预测用状态方程 x̂⁻ = A x̂ + B u 推演先验，协方差 P⁻ = A P Aᵀ + Q；更新用观测 z 校正后验：K = P⁻ Hᵀ (H P⁻ Hᵀ + R)⁻¹, x̂ = x̂⁻ + K(z - H x̂⁻)。

### Q3.2（21 关）EKF 与线性 Kalman 的区别？
参考答案：EKF 对非线性观测模型 h(x) 在当前估计点线性化（Jacobian），适用于小角度近似失效的场景。代价是 Jacobian 计算和线性化误差。

### Q3.3（22 关）最小二乘辨识为什么要训练/测试分离？
参考答案：防止过拟合——参数在训练集拟合好但在测试集外推失败。课程用 70% 数据辨识，30% 验证。

### Q3.4（23 关）二次规划的约束残差是什么？
参考答案：约束残差是 ||Ax - b|| 或 max(0, g(x))，衡量解的可行性。课程要求残差 < 1e-6。

### Q3.5（20 关）过程噪声协方差 Q 与观测噪声协方差 R 如何标定？
参考答案：R 可从传感器静态数据估计方差；Q 较难直接测量，常用方法：①经验法从小值开始调，直到滤波输出平滑且不滞后；②残差自相关法——新息序列应为白噪声，若自相关不为 0 说明 Q 偏小或模型不准。课程取 Q=diag(1e-3,...), R=diag(1e-2,...)。

### Q3.6（21 关）EKF 的雅可比在哪些情况下需要数值而非解析计算？
参考答案：观测模型 h(x) 含分段函数（如符号函数、饱和）或第三方黑箱函数时，解析导数不可导或不可得。数值雅可比用中心差分 ∂h/∂x ≈ (h(x+δ) - h(x-δ))/(2δ)，代价是计算量大且步长 δ 敏感。

## 第 24-31 关：MPC 与强化学习

### Q4.1（24 关）MPC 的预测时域如何选择？
参考答案：太短无法预判，太长计算量大且模型误差累积。课程取 10 步（100ms），平衡响应与计算。

### Q4.2（27 关）REINFORCE 的梯度估计为什么是无偏的？
参考答案：E[∇log π(a|s) * R] = ∇J(π)，期望意义下等于真实梯度。代价是方差大，需 baseline 降方差。

### Q4.3（28 关）PPO 的 clipped objective 为什么比 TRPO 高效？
参考答案：TRPO 用 KL 散度约束需共轭梯度法解线性方程，PPO 用 ratio 裁剪 r = π_new/π_old ∈ [1-ε, 1+ε] 直接限制更新幅度，避免二阶优化。

### Q4.4（31 关）bootstrap 置信区间如何评估鲁棒性？
参考答案：从评估回报集合有放回采样 N 次，计算统计量分布。若 95% CI 不含 0，说明策略显著优于随机；CI 宽度反映稳定性。

### Q4.5（24 关）MPC 与 LQR 的核心区别是什么？
参考答案：LQR 求解无限时域无约束最优反馈增益 K，离线计算一次后线性反馈；MPC 求解有限时域滚动优化，每步在线求解带约束 QP，把第一个控制量施加给系统后再次滚动。MPC 显式处理输入/状态约束，LQR 不能。

### Q4.6（29 关）PPO 的 GAE 优势估计如何降低方差？
参考答案：GAE 用 λ 在 bias 和 variance 之间插值：A_GAE = Σ (γλ)^l * δ_l，其中 δ_l = r + γV(s') - V(s) 是 TD 误差。λ=0 退化为单步 TD（低方差高偏差），λ=1 退化为 Monte Carlo（高方差无偏差）。课程取 λ=0.95。

### Q4.7（30 关）残差 RL 的基线控制器选择标准是什么？
参考答案：基线必须①在标称条件下稳定（保证训练期安全）；②与 RL 接口简单（输入状态、输出动作）；③不"太强"（否则残差为零，RL 学不到东西）；④不"太弱"（否则训练期频繁跌倒，数据稀疏）。课程选 PD 作为基线。

## 第 32-37 关：VLA 与感知

### Q5.1（33 关）HSV 颜色检测为什么对光照敏感？
参考答案：HSV 中 V（明度）受光照直接影响，固定阈值在不同光照下失效。改进：自适应阈值、深度学习检测、Lab 颜色空间。

### Q5.2（34 关）语言解析器如何支持中英文？
参考答案：用关键词匹配 + 词性标注。"去红色目标" 和 "go to red target" 都映射到 (action=goto, color=red, target=...)。

### Q5.3（36 关）行为克隆的局限是什么？
参考答案：仅模仿专家轨迹，无法处理分布外情况；复合误差：小错误累积导致偏离训练分布。改进：DAgger、RL fine-tuning。

### Q5.4（37 关）VLA 评估为什么要报告安全指标？
参考答案：成功率不够，还要看是否触发安全状态。课程要求报告 collision_rate、safety_state_transition_count、recovery_success_rate。

### Q5.5（32 关）VLA 的"V""L""A"分别指什么？三者如何耦合？
参考答案：V=Vision（视觉感知，相机图像）、L=Language（语言指令，如"去红色目标"）、A=Action（动作输出，如关节目标或轮速）。耦合方式：视觉和语言编码后拼接/交叉注意力，经策略头输出动作；课程实现是 ResNet 视觉编码 + 词袋语言编码 + MLP 动作头。

### Q5.6（35 关）专家轨迹采集时如何保证多样性？
参考答案：①初始状态随机化（位置、俯仰、目标颜色）；②指令随机化（中英文、不同句式）；③扰动随机化（外力、地形变化）；④专家策略多样化（PD、LQR、人工演示混合）。多样性不足会导致策略过拟合到单一分布。

### Q5.7（37 关）safety_state_transition_count 高说明什么？
参考答案：说明策略频繁触发安全状态机跳转（如进入 FAULT 或 SELF_CHECK），反映策略在评估场景下不稳定。理想值应接近 0；过高需检查是否训练分布与评估分布不匹配，或安全阈值过严。

## 第 38-43 关：工程部署与安全

### Q6.1（38 关）C++ 和 Python 数值一致性如何验证？
参考答案：固定 seed 生成 1000 组输入，分别喂给 C++ 和 Python 实现，逐项比较输出。容差 1e-9（浮点数精度）。

### Q6.2（39 关）CMake 依赖图能暴露什么问题？
参考答案：循环依赖、未声明的头文件依赖、PUBLIC/PRIVATE/INTERFACE 误用。课程测试：关闭公共头文件导出后能否复现构建。

### Q6.3（40 关）ROS2 SensorDataQoS 与默认 QoS 的区别？
参考答案：SensorDataQoS = BEST_EFFORT + KEEP_LAST(depth=5)，允许丢包但低延迟；默认 = RELIABLE + KEEP_LAST(depth=10)，保证送达但可能堆积。传感器数据用前者避免延迟。

### Q6.4（41 关）Windows 1ms 定时器分辨率对 100Hz 控制的影响？
参考答案：默认 15.6ms 分辨率下，100Hz（10ms）周期会抖动到 15.6ms 或 7.8ms。timeBeginPeriod(1) 后分辨率降到 1ms，平均周期更接近 10ms。但不是硬实时保证。

### Q6.5（42 关）日志契约为什么用 JSON lines 而不是 CSV？
参考答案：JSON lines 自描述字段名，扩展字段不破坏旧解析器；CSV 依赖列顺序，扩展需协调。代价是体积略大。

### Q6.6（42 关）timestamp_ns 严格递增（相等返回 false）的动机？
参考答案：相同时间戳意味着两次 tick 共用一个时钟读数，可能丢帧或时钟回退。严格递增便于检测时钟异常。

### Q6.7（43 关）为什么 FAULT 不自动恢复？
参考答案：故障可能由硬件损坏或软件 bug 引起，自动恢复可能放大故障。强制人工复位确保操作者检查现场、定位根因后再重启。

### Q6.8（43 关）俯仰安全阈值 0.3 rad（约 17°）如何选择？
参考答案：小角度线性化在 0.25 rad 内有效（5% 误差），0.3 rad 留 20% 余量。超过 0.3 rad 时线性控制器已失效，进入 FAULT 更安全。

### Q6.9（38 关）C++ 中 `std::atomic` 与 `std::mutex` 在控制循环中如何选择？
参考答案：单变量读写用 atomic（无锁、低延迟），如安全标志位、急停标志；多变量一致性更新用 mutex（保证原子事务），如状态机的多字段同时变更。控制循环中尽量避免 mutex 长持有，避免抖动。

### Q6.10（41 关）`timeBeginPeriod(1)` 为什么要在进程退出时配对调用 `timeEndPeriod(1)`？
参考答案：timeBeginPeriod 全局影响系统定时器分辨率，不配对释放会导致系统整体功耗上升、其他进程调度异常。配对调用是资源卫生的基本要求；课程测试会在退出后验证分辨率恢复。

## 第 44-47 关：系统设计、综合、故障演练、答辩

### Q7.1（44 关）接口契约文档为什么必须列 QoS？
参考答案：QoS 决定消息可靠性 vs 延迟权衡。订阅者用错 QoS 会导致收不到消息（reliable 订阅 best_effort 话题）或延迟堆积。

### Q7.2（45 关）综合评分 system_score = min(code, physics, robustness, realtime, safety, docs) 为什么取 min？
参考答案：木桶原理——任一维度短板都会影响整体可用性。取 min 强制所有维度达标，避免"代码好但安全差"的伪合格。

### Q7.3（46 关）故障演练为什么要注入 4 类故障（传感器/执行器/通信/软件）？
参考答案：覆盖故障树主要分支——传感器失效、执行器饱和、通信中断、软件 bug。每类对应不同检测机制和恢复策略。

### Q7.4（47 关）代码评审报告应该包含哪些指标？
参考答案：模块数、覆盖率（行/分支）、平均圈复杂度、重复代码比例、静态分析告警数、安全 lint 通过项。课程要求覆盖率 ≥80%，无严重告警。

### Q7.5（44 关）系统设计文档应该覆盖哪五要素？
参考答案：①组件清单（节点/模块及其职责）；②数据流（话题、消息类型、频率）；③接口契约（QoS、字段语义、单位）；④资源约束（CPU、内存、带宽、时序）；⑤失败模式（每个组件的故障行为与降级策略）。五要素缺一不可，否则评审不通过。

### Q7.6（45 关）如果 code=90、physics=85、robustness=70、realtime=95、safety=80、docs=88，system_score 是多少？说明什么？
参考答案：min(90,85,70,95,80,88)=70。说明鲁棒性是当前最大短板，应优先投入鲁棒性提升（域随机化扩展、bootstrap CI 收紧、长尾场景训练），而非继续优化已经高分的实时性或代码质量。

### Q7.7（46 关）故障演练的"覆盖度 100%"如何量化？
参考答案：故障树每个叶子节点至少被一次注入测试触发，且对应检测/恢复路径被验证。量化公式：覆盖度 = 已验证叶子数 / 故障树总叶子数。课程要求 = 100%，少一个叶子即不通过。

### Q7.8（47 关）答辩时如何用 3 分钟讲完整个课程？
参考答案：①问题：让双足轮式机器人在随机化环境中稳定平衡并响应语义指令（30 秒）；②方法栈：PD→LQR→RL→VLA 四层递进，每层补足上层局限（60 秒）；③工程化：C++/ROS2 保证 100Hz 实时，安全状态机保证故障可控（45 秒）；④证据：8 类毕业门槛测试全绿（30 秒）；⑤局限与改进：Sim2Real gap + VLA 闭环（15 秒）。

## 通用问题

### Q8.1 如果指标退化 20%，先查模型、数据、控制还是部署？
参考答案：先查部署——部署变化（QoS、定时器、依赖版本）最容易引入隐性退化且最先可观测（日志异常）。其次数据（分布漂移），再次控制（参数漂移），最后模型（结构变化）。

### Q8.2 用哪三份证据证明结果可复现？
参考答案：(1) 固定 seed 的测试日志，(2) 结果契约 JSON（含 git_commit、metrics、pass_conditions），(3) portfolio 报告（含图表和数据来源说明）。

### Q8.3 本项目最关键的假设是什么？失效时第一个可观测信号？
参考答案：假设小角度线性化在 |pitch|<0.3 rad 内有效。失效信号：safety_flag=2（力矩饱和）或 safety_state=FAULT。

### Q8.4 项目中哪一项工程实践最容易被新手忽视但最关键？
参考答案：接口契约文档。新手倾向于直接写代码、跑通就算完，但 QoS 错配、单位不一致、字段语义歧义会在集成阶段爆发，且难以定位。课程第 44 关专门强制接口契约文档化。

### Q8.5 如果只能保留一个测试，保留哪个？为什么？
参考答案：保留 `test_safety_state_machine.cpp`。原因：安全是部署底线，状态机一旦失效可能导致硬件损坏或人身伤害；其他维度（控制、RL、VLA）退化只是性能下降，安全失效是事故。安全测试覆盖 15 个 gtest，含状态转移、阈值触发、急停、不自动恢复等关键路径。

### Q8.6 课程为什么用 Python 教学但用 C++ 部署？
参考答案：Python 生态（gymnasium、torch、mujoco bindings）适合快速实验和算法迭代，新手门槛低；C++ 适合硬实时、低延迟、工业部署。两者通过数值一致性测试桥接，既保留教学友好性又保证部署可行性。

### Q8.7 项目中"小白原则"如何体现？举例说明。
参考答案：每一概念先用高中数学可理解的方式引入，再逐步加深。例如 PD 控制：先讲"弹簧—阻尼"直觉（u = Kp*e + Kd*ė），再讲临界阻尼条件 2*sqrt(Kp*J)≈Kd，最后才引入状态空间和 LQR。避免一上来就讲 Riccati 方程。
