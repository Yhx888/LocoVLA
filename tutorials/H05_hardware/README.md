# H05 AS5600 编码器与标定

## 岗位任务

把原始 12 位角度变成方向正确、跨零连续、可诊断磁场质量的轮角度和角速度。

AS5600 使用 I2C。读取角度前先检查磁铁检测状态、最大/最小增益与总线地址冲突。角度跨越 4095 -> 0 时，直接相减会制造一个巨大速度尖峰；必须先做环形差分再除以采样周期。

单位链：计数 -> 圈 -> rad -> rad/s。左右轮轴相反，方向符号必须在硬件契约中显式记录，不能散落在控制代码里。

故意错误：让轮子慢速跨零，观察未经 unwrap 的速度尖峰如何触发力矩限幅。

验收：一圈线性度图、跨零速度曲线、左右方向测试、拔掉编码器后的故障状态。
