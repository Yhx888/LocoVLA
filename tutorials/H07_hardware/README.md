# H07 总线舵机与腿部机构

## 岗位任务

让左右腿从可验证零位运动到安全高度，不撞机械限位，也不因通信冲突失控。

原仓库说明左舵机 ID=1、右舵机 ID=2，完全蹲下机械限位对应 2048，并使用 FEETECH 调试软件。这个数值只能作为原项目线索，不能直接写入你的实机；先断开连杆确认方向，再小范围运动，最后建立角度-计数-腿高映射。

总线读写是分时复用。控制循环必须给通信设置超时，旧反馈超过新鲜度门槛时禁止继续增大动作。

故意错误：交换左右 ID，要求安全层在腿部运动前通过回读型号、ID 和零位发现问题。

验收：ID 清单、软限位、同步运动曲线、堵转/失联保护和腿高重复性。
