## 复盘与面试

1. 本关最关键的假设是什么？失效时第一个可观测信号是什么？

<!-- upkie-qa:H07-q1 -->
最关键的假设是：`servo_count → joint_angle → leg_height` 这条正向运动学链是确定性的——即给定舵机的 PWM 脉宽（count），关节角度（joint_angle，rad）是唯一的，给定关节角度，腿部末端高度（leg_height，m）也是唯一的。这个假设依赖两个前提：一是舵机的 count-角度标定是准确的（知道 1500 count 对应 0°，而不是偏差 5°）；二是腿部机构的几何尺寸与图纸一致（连杆长度、关节偏移量没有加工误差）。假设失效时，第一个可观测信号不是机器人翻倒，而是运动学预测与实际位置不符：如果标定偏差，发送"腿部高度 100 mm"的指令后，实测高度可能是 95 mm 或 105 mm，机器人重心位置与控制器预期不符，平衡控制会出现稳态偏差（总是向一侧倾斜）；如果机构有间隙（关节配合松动，H02 章的 clearance 过大），同一个 servo_count 指令下关节角度会在一个范围内晃动，leg_height 不可重复。本关正文的"先低能量验证，再逐级闭环"在这里的体现是：先手动移动腿部到多个已知位置，验证正运动学计算与实测一致，再低速运行验证轨迹跟踪，最后才接入平衡控制。需要注意的是，本关当前建设状态为"规划中"，`course_checkpoint.py --chapter H07` 会明确拒绝验收。面试时的判断框架：运动学问题的排查顺序是"标定 → 机构间隙 → 舵机响应 → 控制指令"，大多数位置误差来自标定和机构，而不是舵机本身。常见误区是"位置不准就调控制增益"——如果根因是标定偏差，调增益只会让系统更积极地追踪错误的目标位置。
<!-- /upkie-qa -->

2. 为什么当前接口、单位和限幅这样设计？有哪些可替代方案？

<!-- upkie-qa:H07-q2 -->
`servo_count → joint_angle → leg_height` 的三级转换把"控制器能发出的指令"（PWM 脉宽，count）和"控制目标"（腿部高度，m）连接起来。joint_angle 用 rad（与课程软件部分的关节角度单位一致，第 38 章的状态向量里 `e_pitch` 是 rad），leg_height 用 m（SI 单位），servo_count 是无量纲的 PWM 脉宽计数（典型范围 500~2500，对应 0~180°）。限幅设计有两层：关节角度限幅（每个关节的物理运动范围，比如髋关节 ±45°、膝关节 0~90°，超出范围会机械干涉或损坏）和腿高限幅（最小腿高受机构折叠极限限制，最大腿高受连杆完全伸展限制，超出范围正运动学无解或机构锁死）。本关正文要求"所有物理量使用 SI 单位"，但 servo_count 是舵机接口的原生单位，转换为 rad 需要标定系数（rad/count），这个标定系数必须在实际上电前通过测量确定，不能从数据手册里直接查到（数据手册给的是典型值，个体差异可达 ±5°）。替代方案：用位置式舵机的角度反馈（某些总线舵机内置电位器或磁编码器，可以直接读取实际关节角度，消除 count-角度标定的不确定性）；或者用步进电机代替舵机（开环位置控制，不需要标定，但力矩密度低、需要驱动器）。需要注意的是，本关当前为规划中状态，具体的关节限幅和腿高范围尚未确定。面试时的判断框架：腿部机构接口设计的核心问题是"控制指令和物理位置之间的映射是否可逆且唯一"，正运动学（joint→position）总是唯一的，逆运动学（position→joint）可能有多解或无解，需要在设计阶段明确工作空间。常见误区是"舵机到了目标 count 就等于关节到了目标角度"——舵机有死区（dead band），在目标位置附近会停止响应，实际角度可能偏差 1~2°，这个误差在精密平衡控制里不可忽略。
<!-- /upkie-qa -->

3. 你能用哪三份证据证明结果可复现？

<!-- upkie-qa:H07-q3 -->
腿部机构的可复现性证据需要覆盖"标定精度、运动学精度、重复性"三个层次。第一份是舵机标定记录：对每个舵机，在多个已知机械角度（比如每 15° 一个点）下记录对应的 servo_count，拟合 count-角度线性关系（斜率和截距），记录拟合残差；这是标定质量的直接证据，让别人能用同样的夹具重测得到相近的标定系数。第二份是正运动学验证记录：发送多组 joint_angle 指令（比如腿高 80/90/100/110 mm），用卡尺或激光测距仪测量实际 leg_height，计算与正运动学预测的偏差；这是 `servo_count → joint_angle → leg_height` 整条链路的端到端验证，偏差来源包括标定误差、机构间隙和连杆尺寸误差。第三份是重复性记录：同一个 leg_height 指令重复执行 10 次，测量每次的实际位置，计算标准差；这是机构间隙和舵机死区的量化证据，标准差越大说明机构精度越差，平衡控制的稳态误差下限就越高。三份证据的分工：标定记录回答"舵机指令和关节角度的关系对不对"，运动学记录回答"关节角度和腿部位置的关系对不对"，重复性记录回答"同一个指令能不能得到同一个结果"。需要注意的是，本关当前为规划中状态，这三份证据的具体格式和验收标准尚未建立。面试时的判断框架：机构证据的可复现性依赖固定的测量基准——卡尺的零点、夹具的定位面都必须一致，不记录测量基准的位置数据没有可比性。常见误区是"只测一次位置"——单次测量无法区分系统误差（标定偏差）和随机误差（机构间隙），重复测量是必须的。
<!-- /upkie-qa -->

4. 如果指标退化 20%，你先查模型、数据、控制还是部署？为什么？

<!-- upkie-qa:H07-q4 -->
先查部署，在腿部机构语境下对应的是"机械装配和舵机状态"。如果腿部高度控制精度退化 20%（比如稳态误差从 2 mm 增大到 2.4 mm），最可能的根因是机械层面的变化，而不是运动学算法——正运动学公式一旦写好不会自己退化，标定系数也不会自动改变。排查顺序：第一步查机械装配（关节螺丝是否松动、连杆连接处是否有磨损间隙——H02 章的 clearance 会随使用增大，间隙增大会让同一个 servo_count 对应的 joint_angle 范围变宽，leg_height 不可重复）；第二步查舵机状态（舵机齿轮是否磨损、电位器是否漂移——舵机使用一段时间后，内部电位器的阻值-角度关系会变化，导致 count-角度标定失效）；第三步查供电（舵机供电电压是否下降——电压不足时舵机扭矩下降，在负载下无法到达目标位置，出现稳态位置误差）。运动学参数（连杆长度、关节偏移）是最后才查的，因为这些参数是机械尺寸，除非有人换了零件，否则不会变化。模型和数据完全不相关——正运动学是几何计算，不涉及任何训练模型。本关正文的"先低能量验证，再逐级闭环"在这里的排查体现是：先断开负载（把腿部机构从机器人上拆下来），空载运行舵机，确认舵机本身的位置精度正常；如果空载正常但装上机器人后退化，说明问题在机械装配或负载，而不是舵机。面试时的判断框架：机构精度退化的排查顺序是"装配间隙 → 舵机磨损 → 供电 → 标定参数"，从最可能到最不可能。常见误区是"误差大就重新标定"——如果根因是机械间隙，重新标定只能补偿系统偏差，不能消除随机晃动，间隙问题必须通过机械修复解决。
<!-- /upkie-qa -->
