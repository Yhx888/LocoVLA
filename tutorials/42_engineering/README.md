# 42 日志、测试与性能分析

## 岗位任务

面对“机器人偶尔抖一下”，你需要用证据回答何时、哪个状态、哪个控制量先异常，而不是录一段视频后猜参数。

## 统一日志字段

每行至少包含单调时钟、episode/运行编号、配置摘要、Git commit、状态、原始动作、限幅后动作、安全标志和循环耗时。日志与仿真统一实验结果 JSON 使用同一字段语义。

测试分三层：纯函数单元测试、节点接口测试、带时间预算的系统测试。性能分析先确定问题是 CPU、内存分配、锁等待还是 I/O，再选择 profiler。

## 验收

```bash
colcon test --event-handlers console_direct+
colcon test-result --verbose
```

生成一张周期延迟直方图和一张状态-力矩时间序列。故意删除一条时间戳，确认分析脚本会拒绝无法排序的日志，而不是静默补零。

作品集：测试矩阵、性能火焰图或 trace、一次故障复盘。
