# 第6章：训练你的第一个强化学习策略

> 🎯 **本节目标**：使用 PPO 算法训练一个让机器人站立的策略。

## 你将学到什么

完成本节后，你将能够：
- 使用 SB3 PPO 进行短时间训练
- 理解 TensorBoard 日志
- 评估和录制 policy

## 什么是强化学习？

强化学习是机器学习的一种方法，智能体通过与环境交互来学习最优策略。

> 💡 **类比**：想象你在训练一只小狗。小狗做对了动作，你就给它奖励；做错了，就不给奖励。小狗会慢慢学会哪些动作能获得奖励。

## 第一步：运行训练脚本

```powershell
python scripts/06_train_ppo_standing.py --total-timesteps 1000
```

运行后，你会看到训练进度输出，以及类似这样的信息：
```
训练完成，模型保存到: outputs/checkpoints/ppo_standing_latest.zip
```

> ⏳ **等待时间**：训练可能需要几分钟，取决于你的电脑性能。

## 第二步：理解训练过程

### PPO 算法

PPO（Proximal Policy Optimization）是一种流行的强化学习算法，它的优点是：
- 稳定：不容易出现训练崩溃
- 高效：样本效率高
- 简单：实现相对简单

### 训练流程

1. 创建环境
2. 创建 PPO agent
3. 训练指定步数
4. 保存 checkpoint

## 第三步：查看训练日志

训练完成后，会在 `outputs/` 目录下生成日志文件。你可以使用 TensorBoard 查看训练曲线：

```powershell
tensorboard --logdir outputs/logs/tensorboard
```

## 第四步：评估训练结果

运行评估脚本，看看训练效果：

```powershell
python scripts/08_eval_policy.py --episodes 1
```

运行后，你会看到类似这样的输出：
```
评估 returns: [396.7200000000013]
```

> 🔍 **这个数字是什么意思？**
> `returns` 是累积奖励，数值越大表示策略越好。

## 试试看：小挑战

1. **增加训练步数**：把 `--total-timesteps` 改成 10000 或 100000，观察训练效果变化。

2. **修改超参数**：打开 `configs/rl/ppo_standing.json`，修改学习率或其他超参数，观察训练效果变化。

3. **对比不同策略**：训练多个不同参数的策略，对比它们的性能。

## 常见问题

| 问题 | 解决方案 |
|---|---|
| 训练不收敛 | 检查 reward 函数设计 |
| 内存不足 | 减少 `total-timesteps` |
| 训练太慢 | 检查电脑性能，或减少训练步数 |
