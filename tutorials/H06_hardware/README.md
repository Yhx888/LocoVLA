# H06 MPU6050 与姿态估计

## 岗位任务

从有零偏、噪声和振动的加速度计/陀螺仪得到控制可用的俯仰角与角速度，并量化静态漂移和动态延迟。

陀螺仪短时响应快但积分漂移；加速度计长期指向重力但会把机体加速度误当成倾斜。互补滤波用高通陀螺仪和低通加速度计互补：

\[
\theta_k=\alpha(\theta_{k-1}+\omega_k\Delta t)+(1-\alpha)\theta_{acc,k}
\]

公式假设采样周期已知、加速度长期均值接近重力。猛烈加速、轮子撞击和传感器饱和时该假设失效。

故意错误：把 `dt` 固定为 0.01 s，同时故意让循环抖动，比较真实时间戳积分的漂移差异。

验收：六面静态标定、10 分钟零偏、手动摆动对比、滤波延迟与失联处理。
