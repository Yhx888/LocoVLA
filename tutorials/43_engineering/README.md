# 43 部署、安全与故障恢复

## 岗位任务

把“节点启动了”升级为可安全上线、可回滚、失联后不会继续输出危险力矩的部署单元。

## 安全状态机

`BOOT -> SELF_CHECK -> DISARMED -> ARMED -> FAULT`。只有传感器新鲜、姿态在安全区、急停释放且操作者显式解锁时才能进入 `ARMED`。任何状态超时、NaN、通信失联或俯仰超限都进入 `FAULT`，输出零轮端力矩并要求人工复位。

语言模型和高层任务只能提交速度/目标请求，不能绕过 `DISARMED`、力矩限幅和急停。

## 故障演练

依次注入 IMU 断流、时间戳倒退、左右轮符号互换、CPU 过载和高层命令失联。每次记录检测延迟、制动延迟、最终状态和恢复步骤。

验收门槛：所有故障都在定义时间内进入安全状态；恢复必须显式确认，不能自动重新解锁；部署包能回滚到上一个已知版本。
