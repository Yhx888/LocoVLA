# H10 参数辨识、Sim2Real 与实机答辩

## 岗位任务

用实机日志反推质量、轮径、摩擦、执行器死区和延迟，把差异写回仿真分布，并完成可复现答辩。

一次只辨识一组参数：轮子离地识别电机/编码器，低速直行识别轮径与方向，小角度扶持实验识别平衡动力学，安全推扰识别恢复能力。参数必须带单位、置信区间、数据范围和失效条件。

Sim2Real 不是让仿真曲线“看起来像”，而是让固定输入下的关键响应落在实机不确定性区间。不能用同一批日志既调参又宣称验证通过。

毕业答辩展示：BOM 与许可、系统架构、安全状态机、控制推导、辨识数据、失败案例、仿真-实机对比、实时性和改进计划。

八类门槛：代码测试、物理指标、鲁棒性、实时性、安全、文档、设计评审、口头答辩。任一门槛缺证据都不是“已完成”。

作品集：完整仓库链接、演示视频、实验报告、故障复盘和一页岗位能力矩阵。
