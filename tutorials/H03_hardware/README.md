# H03 供电、PCB 与安全检查

## 岗位任务

在插电前证明电池极性、电压、限流、地线和驱动器没有把单点错误变成烧板或失控。

原仓库特别提示电源正负丝印曾修正，其他品牌电池必须重新核对极性；L6234PD013TR 也存在供应链假货风险。不要把丝印、商品页和实物任一项单独当成真相，用万用表连续性与二极管档交叉验证。

首次上电使用限流电源，断开电机和舵机负载，按 0.1 A、0.3 A、目标待机电流逐级提高。记录每级输入电压、电流、3.3 V/5 V 轨电压和异常温升。

故意错误：在断电状态注入一处反接标记，让同伴只按检查单定位，不靠记忆。

验收：上电前检查单、限流曲线、热像/温度证据、保险与急停方案。
