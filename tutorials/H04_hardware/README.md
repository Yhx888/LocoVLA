# H04 ESP32、SimpleFOC 与无刷电机

## 岗位任务

让每个轮电机先在离地、限流、可急停条件下完成相序、传感器方向和力矩方向标定，再接平衡环。

原仓库使用 Arduino IDE、ESP32 与 SimpleFOC，并建议 ESP32 core 2.0.3、仓库内 WebSocket 库。课程不把“能编译”当成版本兼容：必须锁定 Arduino core、SimpleFOC 版本、板卡包、编译选项和库 commit，保存完整构建日志。

FOC 分三层：电流产生磁场，电角度决定磁场方向，外层力矩命令决定希望产生多大切向力。相序或编码器方向错时，闭环会把误差放大，症状可能是抖动、啸叫、过流或初始化反转。

故意错误：交换任意两相，比较初始化日志与电流，不允许靠反复上电试运气。

验收：离地正反转、0.1/0.2/0.3 N·m 阶跃、限流触发、急停断矩和版本锁文件。
