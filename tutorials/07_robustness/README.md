# 第7章：让策略更鲁棒——域随机化

> 🎯 **本节目标**：理解为什么仿真控制器容易过拟合，学会使用域随机化提高策略鲁棒性。

## 你将学到什么

完成本节后，你将能够：
- 理解仿真与真实世界的差距
- 实现 sensor noise、action delay、push disturbance
- 理解 domain randomization

## 为什么需要鲁棒性？

仿真环境是理想化的，真实世界有：
- **噪声**：传感器数据有噪声
- **延迟**：动作执行有延迟
- **干扰**：外部有推力、摩擦等干扰

如果策略只在理想环境中训练，到了真实世界就会失败。

## 第二步：理解域随机化技术

### Sensor Noise（传感器噪声）
在传感器数据中添加随机噪声。

### Action Delay（动作延迟）
模拟动作执行的延迟。

### Push Disturbance（推力干扰）
模拟外部推力干扰。

### Dynamics Randomization（动力学随机化）
随机化物理参数，如质量、摩擦等。

## 第三步：探索配置文件

让我们看看随机化配置：

```powershell
type configs\randomization\default.json
```

你会看到类似这样的内容：
```json
{
  "sensor_noise": {...},
  "action_delay": {...},
  "push_disturbance": {...}
}
```

## 第四步：理解 Sim2Real Gap

Sim2Real Gap 是指仿真与真实世界之间的差距。域随机化的目的是缩小这个差距。

> 💡 **类比**：想象你在室内练习投篮。如果只在无风的环境中练习，到了有风的室外就会失败。域随机化就像在练习时加入各种干扰，让你适应不同环境。

## 试试看：小挑战

1. **修改随机化参数**：打开 `configs/randomization/default.json`，修改随机化范围，观察策略效果变化。

2. **对比有无随机化**：分别训练有随机化和无随机化的策略，对比它们的鲁棒性。

3. **添加新的随机化**：尝试添加新的随机化类型，如地面摩擦随机化。

## 常见问题

| 问题 | 解决方案 |
|---|---|
| 随机化效果不明显 | 增大随机化范围 |
| 训练不稳定 | 减小随机化范围 |
