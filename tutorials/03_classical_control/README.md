## 什么是经典控制？

经典控制是控制理论的基础，包括：
- **PD 控制**：比例-微分控制，最基础的反馈控制
- **LQR 控制**：线性二次调节器，一种最优控制方法

> 💡 **为什么叫"经典"？** 因为这些方法已经存在几十年了，是现代控制理论的基础。

## 第三步：理解 PD 控制

PD 控制是最基础的反馈控制，包含两项：
- **P（比例）**：根据当前误差调整
- **D（微分）**：根据误差变化率调整

> 💡 **类比**：想象你在开车，P 项告诉你"偏了多少"，D 项告诉你"偏得有多快"。

### 控制公式

```
u = Kp * error + Kd * error_rate
```

其中：
- `u`：控制输出
- `Kp`：比例增益
- `Kd`：微分增益
- `error`：当前误差
- `error_rate`：误差变化率

## 常见问题

| 问题 | 解决方案 |
|---|---|
| 控制器不稳定 | 调整 `configs/control/pd.json` 中的增益参数 |
| 机器人摔倒 | 检查初始姿态设置，可能需要调整 `configs/robot/upkie.json` 中的 `default_pose` |
