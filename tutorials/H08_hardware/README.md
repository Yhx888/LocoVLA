# H08 实机 LQR、限幅与急停

## 岗位任务

把仿真控制器迁移到实机，但先证明单位、方向、平衡点和安全链一致，再扶持站立。

实机误差向量为 `[位置误差, 速度误差, 俯仰误差, 俯仰角速度]`。平衡点必须从实机质心和轮轴重新辨识，不能沿用 Upkie 的 `0.142 rad`。力矩命令依次经过增益、低通、变化率限制、绝对限幅和急停门控。

上机顺序：轮子离地验符号 -> 支架限制俯仰 -> 人工扶持低增益 -> 小扰动 -> 短时自主 -> 长时热稳定。每一级都设置退出条件。

故意错误：注入右轮符号反转，安全层应在离地阶段通过同向速度检查阻止解锁。

验收：急停制动延迟、最大俯仰、最大电流、恢复流程和一次参数变更评审。
